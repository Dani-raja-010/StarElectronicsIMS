# IMS Project Guidelines

When editing or generating code for this Inventory Management System:
1. Adhere to C# Windows Forms conventions used in this repository.
2. Ensure database queries align with the schema in `se.mdf` / SQL Server configuration.
3. Keep UI component logic separated from database access methods.
